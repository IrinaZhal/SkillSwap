# SkillSwap

Краткое описание проекта

**Это современный веб-проект на [React/TypeScript], предназначенный для обмена навыками «Я научу / Хочу научиться»**

ТЗ: создать в команде MVP веб-проекта для обмена навыками.

Мной были реализованы следующие части проекта:
1. Выполнены несколько UI-компонентов для страницы профиля (как с нуля, так и с с переиспользованием компонентов, созданных другими участниками): меню для навигации, форма личных данных пользователей, элемент для смены атарки.
2. Создан компонент Profile, который отвечает за логику работы страницы профиля - добавлена валидация для полей имени и email, подгрузка данных из моковых файлов.
3. Добавлен UI-компонент модального окна "Все навыки".
4. Для компонентов утилит и кастомных хуков, написанных другими участниками, созданы юнит-тесты с использованием jest и React Testing Library.
---

## ⚙️ Технологии

- **Frontend**: React 18, TypeScript, Vite, CSS-modules
- **Линтинг**: ESLint (+ Airbnb), Prettier, Stylelint

## 📦 Установка зависимостей

Перед запуском убедитесь, что у вас установлен [Node.js](https://nodejs.org/) (версия 18+) и [npm](https://www.npmjs.com/) / [Yarn](https://yarnpkg.com/).

```bash
# Клонируйте репозиторий (ветку develop)
git clone https://github.com/PM-YandexPracticum/SkillSwap_30_3
cd ваш-проект

# Установите зависимости
npm install
# или
yarn install

#Запуск проекта
npm run dev

#Production сборка
npm run build

# Проверка стиля кода
npm run lint

# Автоисправление ошибок
npm run lint:fix

# Форматирование кода
npm run format
```
